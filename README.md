# Note Garden

A prototype adaptive music book for kids. Pip the bird listens through the microphone to check each note a child plays, and the book adapts as they learn: color, letter and piano-key helpers fade away as notes are mastered.

- **Songbook**: six pages from "Hello, C!" to "Twinkle, Twinkle", plus a practice page built from the trickiest notes.
- **Echo Bird**: ear training, where Pip sings a note and the child plays it back.
- **Bubble Pop**: note reading against floating bubbles, with speed that adapts.
- **Grown-ups' corner**: per-note mastery and microphone sensitivity.

Open the page, click **Listen to my instrument**, and play. Any instrument works, since octave doesn't matter. The on-screen piano and computer keys A S D F G H J K work without a microphone.

Everything lives in `index.html`; progress is saved in the browser.
