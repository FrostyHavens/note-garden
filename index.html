    Note mastery

    How Pip adapts

    • New notes start with four helpers: color, letter name, a glowing piano key, and Pip singing on request.
    • After 4 first-try notes in a row, one helper fades. Glowing key first, then the letter, then the color. In the end the note looks like plain sheet music.
    • Two wrong tries bring a helper back and Pip sings the note.
    • Pip's Practice Page and Bubble Pop pick the trickiest notes more often.
    • Bubble Pop speeds up after pops and slows down when bubbles get away. It also remembers the last speed.

    Listening

    Pip listens for which note is played. The octave doesn't matter, so piano, xylophone, recorder, ukulele or singing all work. Pip stops listening while it sings so it doesn't hear itself.
